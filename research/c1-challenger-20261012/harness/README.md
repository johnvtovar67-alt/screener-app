No historical run has been performed. `implementation-inventory.json` identifies all 48 supported alternatives, but support and synthetic verification do not establish performance. The legacy options-only wrapper remains unchanged; `research-loader.cjs` combines its supported option families with the signal, exit and regime overlays.

The loader requires explicit `audit-historical` or `production-equivalent`. Only Champion may use the historical audit; every Challenger uses production-equivalent source. The no-op Champion uses the exact preserved loader. Other variants record original/effective source hashes, compiler/exposure/option transforms and matrix identity. The pinned replay and recorded verifier are unchanged on disk; the verifier's only in-memory seam selects the research loader. A supplemental comparison verifies the complete effective source identity, excluding only cached versus uncached mode.

`run-historical.cjs` is deliberately fail-closed. Its private gates file must contain G0/G1/G3/G4 for baseline runs, additionally G2 for development/validation, with `passed:true` and 64-character SHA-256 `receiptSha256` for each. These are independent acceptance observations, not attestations generated by the runner. It also requires the frozen `matrixSha256`, `privateStorageAcceptance` with evidenced provider-permitted private storage of exact originals, and `codePersistence` with remotely verified immutable commit and current research files verified. See `verifyAcceptance` for the exact contract. Passing receipt fields must be backed by actual checks; inventing them is not authorized.

Accepted-data and original-warmup roots must be existing private directories outside this public repository. Outputs require an existing directory under the explicit private root, a new versioned filename, exclusive creation and private permissions. Every accepted dataset must match the exact published Champion manifest; signal preparation independently verifies the complete original archive. Original inputs are never overwritten or rebuilt. `--conditional-inputs` explicitly permits the known archived live-input rejection; it never changes the non-alpha interpretation.

## Exact private explanatory inputs

`analysis-inputs.cjs` prepares the original source SPY warmup/history and unheld-symbol opportunity marks for the analysis CLI. It performs no strategy run or signal recompilation. It requires an explicit source baseline, the exact published Champion input manifest, baseline-stage G0/G1/G3/G4 acceptance, licensed exact private preservation and verified persisted research code. Input and output directories use the same private confinement guards as the replay runner.

After those external gates actually pass:

```sh
node research/c1-challenger-20261012/harness/analysis-inputs.cjs \
  --baseline production-equivalent --data-root /PRIVATE/ACCEPTED \
  --private-root /PRIVATE/RESEARCH --gates /PRIVATE/RESEARCH/accepted-gates.json \
  --spy-output /PRIVATE/RESEARCH/spy-history-v1.json \
  --opportunity-output /PRIVATE/RESEARCH/opportunity-marks-v1.json \
  --receipt-output /PRIVATE/RESEARCH/analysis-inputs-v1.receipt.json \
  --conditional-inputs
```

The three new files are private and exclusively created with mode 0600. The receipt is written last and binds source identity, exact manifest, unchanged common source dataset digest, pinned compaction and output hashes. Existing versions, symbolic links, public repository paths and output escapes fail closed. Interrupted extraction may leave partial private files; all three files and matching hashes are required for completed extraction.

The arrays retain every loaded source session, price-row order and original close value. Missing/nonfinite marks remain unavailable; no carry-forward, interpolation, substitute price or reconstructed history is supplied. Source audit encoding preserves those values. Pass the first array to analysis `--spy-history` and the second to `--opportunity-marks`. These row-level files, including warmup, must remain private. Their availability provides diagnostic inputs, not a comparative performance finding or certified alpha.

Run `node research/c1-challenger-20261012/harness/analysis-inputs-regression.cjs` for invented extraction and private-writer checks. It never fabricates accepted historical gates or provider licensing evidence.
