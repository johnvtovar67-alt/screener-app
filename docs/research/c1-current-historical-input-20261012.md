# Source-current historical input derivation

The owner authorized recreation of the missing C1 validation continuation, using current production policy and verified recovered historical inputs, without optimization or strategy-parameter changes. The original archive compiler accepted short histories (default 20 rows; position evaluation required 50). Current `compileC1LiveInput` explicitly supplies `minimumHistoryRows: 253` before cross-sectional factors are attached. Filtering already-ranked archived rows would preserve the wrong global/sector percentiles.

`tools/c1-build-current-historical-input.cjs` therefore writes a separate `c1-source-pinned-current253-historical-input-v1` artifact only after complete original-input validation passes. Original compressed chunks, original manifests, checkpoint prices, and membership evidence are read and hash-checked; no original artifact is rewritten. Dated index membership follows the independently verified original compiler convention, including effective changes on the following session and the saved SATS/ECHO identity normalization. All accepted price bars and corporate-action evidence are preserved.

The builder invokes the actual `compilePointInTimeSignals` with the current live 253-row gate and universe-specific candidate cap, then the actual `compactReplaySession`. It uses the current name/sector scalar profile shape, with no archived CIK fields, and empty fundamentals/events as in current production input. Strict mode invokes actual `c1LiveMembers`; conditional mode models its scalar projection while retaining observed source-invalid sectors, rather than submitting an artificial sector-valid subset as a smaller index. The regression proves this projection equals the actual source on valid profiles and preserves `Other` while the source rejects it. No factor, entry-timing, label, or sizing formula is copied. The 253-row filter occurs inside the real compiler before global and sector percentile calculation. Price-only account ranking uses the complete resulting `positionSignals` cohort. No fundamental market cap is invented; the fresh discovery shortlist is consequently empty, just as the actual source compiler establishes from these live inputs.

The strict default invokes the unchanged live member validator and rejects the archive when a member has the archived `Other` sector. It does not write an accepted derived manifest; a separate rejection receipt records the actual source error and pins. The recovered archive also includes a current-member FRC history gap on May 3, 2023 (May 1 and 2 are absent), and early dates lack the full 550-calendar-day benchmark acquisition prefix requested by the live collector. These facts preclude claiming literal end-to-end current live-input acceptance.

The explicitly selected offline `--conditional-archived-metadata` mode uses the distinct `c1-source-pinned-current253-conditional-historical-input-v1` contract. It retains the archived sector labels and observed bars, records the source guard exceptions, and allows the requested conditional account/factor-policy arithmetic to be measured. The manifest and receipt state `actualLiveInputAccepted: false` and `eligibleForAlphaClaim: false`; `passed: true` describes reconstruction, cohort, and source-hash checks only. No application guard is changed and no missing sector, bar, or fundamental is invented. Replay requires its own explicit conditional-input flag and must label these outcomes as conditional current-account-policy counterfactuals.

The archive's fixed 20:00 UTC decision timestamp precedes the 21:00 UTC winter market close. Original timestamps remain immutable and are preserved separately in the receipt. Conditional model sessions use an explicit 21:30 UTC observation, verified by `latestCompletedMarketSessionDay`, so account continuation sees the same completed date and close decisions execute only at the following open. This is a causal model clock, with no claim of actual historical provider collection. The receipt counts original observations before the completed close and all changed modeled timestamps.

Compilation is batched along the original chunk boundaries to bound memory. Current production compiles each newly observed session with fresh continuity memory. Empty fundamentals prevent market-cap-qualified discovery rows in every session; the adapter verifies the discovery shortlist and persisted continuity memory remain empty, so batching cannot change labels through prior days. `tools/c1-current-historical-input-regression.cjs` compares eight resulting sessions, field-for-field, against the actual `compileC1LiveInput` entry point. It includes a 252-row member that must be excluded before percentile ranking, verifies no archived issuer IDs enter the current profile, and confirms original price inputs stay immutable.

The derived acceptance receipt pins all transitive compiler/compaction source files and the adapter, original validation receipt, manifests, checkpoint, and membership blueprint. It records every dated 253-row cohort, excluded short histories, missing current-price members, original source-count equivalence, and derived chunk hashes. The replay must use this separate derived artifact for current-policy claims.

Historical sector/name classifications remain the archived provider classifications, with no independently dated provenance. Missing-current-price members are quarantined before derived membership, matching the current collector, while all accepted original price bars remain available for held/removal evidence. Missing archived profiles may be retained as index members only if they never reach the 253-row factor cohort; their metadata is never fabricated. Historical price snapshots do not establish as-known unrevised prices, and unavailable historical material-event or quote-freshness evidence remains a stated limitation. No production application files or strategy parameters are changed by this input derivation.
