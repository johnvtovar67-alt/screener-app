explicit disposition. Release requires the full unchanged freeze/canonical/
regression/optimized build gates, exact-head CI/preview, reviewed/merged-tree

operational samples and synthetic journey tests must be identified separately.
An aggregate healthy probe cannot certify private brokerage reconciliation or
guarantee that a stock qualifies for a Buy. No test count alone completes this
program, and no pending item may be called done.
