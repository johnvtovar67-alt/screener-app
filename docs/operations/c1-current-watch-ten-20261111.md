## Defect and scoped change

classified Watch row, then rendered the whole list. Removing the source queue
cutoffs had therefore also expanded the Watch presentation. The display lacked
the requested cap and included known disqualifications.

The new pure presentation selector requires a current coherent decision, an
explicitly complete dated source scan, current independent entry evidence and
complete account restriction/exposure evidence. It excludes held names, active
exits, account-wide stock cooldowns, concrete funding/exposure/issuer/capacity
blocks, unavailable observations, and existing source, volatility, recent
momentum, event, quote, liquidity, price, mandate and opening-gap failures.

entry-queue order is an entry-trigger wait, rather than a new hard Watch veto;
all concrete purchase limits remain enforced. No new timing-pass rule is added.

than ten is valid; missing evidence is not padded with blocked leaders. Display

status. A source-scan count does not claim all current entry checks passed.

The source candidates, live provider plan, complete classifier output, account

Portfolio actions and existing holdings remain separate. Pre-v2 presentation
and all historical strategy rules retain their original behavior.

## Ranking and evidence boundaries

The unchanged screen rank is momentum percentile minus 50, rounded to four
places, descending, with alphabetical symbol ties. The factor uses 40% global
percentile of the 120-session return excluding the latest 20 sessions, 25%
global percentile of the 60-session return excluding the latest five, and 22%
and 13% of the corresponding within-sector percentiles. Tied values share their
midpoint percentile; available weights are normalized by the existing evaluator.
There is no prior-Watch-appearance bonus. Long, lagged windows can retain leaders,
but that observation alone does not prove why a particular dated list repeated.

An exact trace requires the accepted dated candidate factors, complete source
and current-evidence counts, and the preceding comparison list. The uploaded
private account predates the current source close and cannot supply that trace.
Current FMP history cannot be substituted for immutable accepted observations.
Available operational logs report broad-screen source/returned row counts only;
they explicitly do not verify C1 selection or complete current entry evaluation.
Missing source data must remain unverified, rather than inferred from those logs.
