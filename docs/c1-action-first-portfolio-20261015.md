# C1 action-first holding decisions

The owner explicitly requested this focused production presentation correction on October 15, 2026: verified existing-stop breaches must say `SELL — STOP TRIGGERED`, other confirmed exits must say `SELL`, and holdings without a confirmed exit must say `HOLD`, followed by one short explanation. Technical calculations and supporting evidence belong in collapsed Details. Opportunities and Portfolio must agree.

`lib/c1PositionPresentation.js` is a read-only shared holding presenter. Accepted pending exits remain authoritative. A new displayed stop breach requires the current account session and either the existing server-verified intraday observation (with its original two-minute expiry/source/revision checks) or an explicitly live/fresh-memory, timestamped stock quote passing existing freshness checks. A bare price, cached freshness boolean, stale quote or conditional standing stop cannot create SELL. A Sell decision does not claim brokerage execution.

`pages/index.js` and `components/C1AccountOpportunities.js` use that same presenter and the same held-stock quote row. Holding status and separate checked capital proposals stay distinct; unsupported additions are hidden without altering any saved order or execution plan. Quote evidence is rechecked at expiry. Technical evidence and the complete original explanation remain available in closed Details. Core behavior is retained.

No momentum policy, threshold, stop, ranking, accounting, simulator, account-storage or execution module changes. No provider calls, data acquisition or account writes are added. Release metadata and only the explicitly authorized application hashes are updated in `docs/c1-release-freeze.json`; its guard and build hooks are unchanged.

Verification includes the permanent action-first regression rendering real desktop/mobile Portfolio and Opportunities with controlled data: DELL-like stop breaches, MPC-like profitable holds, pending exits, stale/future/missing-provenance quotes, expired/wrong-source/revision intraday observations, incomplete momentum evidence, Core exclusion, financial-column alignment and input immutability. Existing evidence UI contracts are updated only for the authorized action/Details layout, retaining trust and accounting checks. Full regression, accounting, simulation and production-build checks are required before release. Mechanical tests make no claim of superior investment returns.
